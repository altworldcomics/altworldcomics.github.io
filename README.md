# AltWorld Comics

Minimal independent publisher website hosted on GitHub Pages.

## Site structure

- `index.html` — homepage and Books, Comics, Authors, Gallery, About sections
- `publisher-minimal.css` and `publisher-minimal.js` — active site design and catalogue rendering
- `data.json` — publication catalogue, cover paths, Amazon links and gallery items
- `books/*/index.html` and `comics/*/index.html` — individual publication pages only
- `images/` — covers, logo and gallery artwork
- `sitemap.xml` and `robots.txt` — search engine discovery

Legacy lore, character profiles and series portals are no longer part of the site. Each publication has one detail page with its description and Amazon link.

Live website: https://altworldcomics.github.io/
