# AltWorld Comics GitHub Pages Site

## Files
- `index.html` — public website
- `admin.html` — local/static admin panel
- `data.json` — all editable content
- `styles.css` — visual design
- `app.js` — site rendering and tab navigation
- `images/` — upload your logos, covers, hero images here

## How to update content
1. Open `admin.html` in the browser.
2. Edit Site Settings, Main Page Posts, Store Items, or About.
3. Click **Download data.json**.
4. Replace the repository's old `data.json` with the downloaded file.
5. Upload any referenced images into the `images/` folder.

## Image path examples
- `images/altworld-comics-logo.png`
- `images/fantomah-hero.jpg`
- `images/fantomah-issue-0-cover.jpg`

## GitHub Pages
Upload all files to a GitHub repository and enable Pages from the repository settings.
