# AltWorld Comics Website — v2

This package upgrades the existing GitHub Pages site into a publisher-style structure.

## Main navigation
Home | Books | Comics | Store | About

## Catalogue model
- Books: original fiction
- Comics: Originals + Remastered Classics
- Store: filterable catalogue; purchase links still go to Amazon
- Work/series pages: dedicated editorial pages for each title or series

## Included detail pages
- KnowAll
- Chronicles of Ankhara: Quest for the Godkiller
- Fantomah series
- Fantomah Issue #0
- Fantomah Issue #1
- Dark Tales series
- Dark Tales #1: Little Red Riding Hood

## SEO
- Dedicated indexable URLs
- Canonical tags
- Open Graph metadata
- JSON-LD structured data
- robots.txt
- sitemap.xml

## IMPORTANT: images/
This ZIP intentionally does NOT duplicate the existing repository's large image files.
Keep the current `images/` folder in the GitHub repository exactly as it is.
All pages reference the image filenames already present in the repository.

Upload/replace the files from this package without deleting the existing `images/` directory.
